## 📝 عن المنصة | About The Platform
منصة **المبدع** هي حل برمجى متطور مصمم خصيصاً للمعلمين والمنصات التعليمية. تركز المنصة على تقديم تجربة مستخدم سلسة للطلاب مع توفير أدوات تحكم قوية للمعلم لإدارة الحصص، الملفات، والطلاب.

**Al-Mobde** is an advanced educational solution tailored for teachers. It provides a seamless experience for students while offering powerful admin tools to manage lessons, files, and student access.

## ✨ المميزات الاحترافية | Key Features

* **🔒 حماية الأجهزة (Device Fingerprinting):** ربط حساب الطالب بجهاز واحد فقط لمنع مشاركة الحسابات.
* **📺 إدارة الفيديو:** تشغيل الحصص التعليمية مع وصف تفصيلي لكل درس.
* **📄 المكتبة الرقمية:** دعم كامل لملفات PDF والمذكرات الدراسية.
* **📝 نظام الاختبارات:** إنشاء اختبارات تقييمية للطلاب ومتابعة النتائج.
* **📊 لوحة تحكم الإدارة:** متابعة حالة الطلاب (نشط/محظور) وإدارة بيانات أجهزتهم.
* **💬 التواصل الذكي:** تكامل مباشر مع WhatsApp و Telegram للدعم الفني.
